2. Entenda o que será feito

Problema no sistema

O catálogo precisa agrupar produtos por categoria. Uma categoria com nome vazio atrapalha a navegação, e uma categoria inativa ainda pode existir no cadastro para preservar seus vínculos.

A mesma classe cresce com um novo grupo de casos de uso, preservando as operações de mesas.

  • texto() exige e limita o nome.
  • opcional() normaliza a descrição; ativo será usado pelas regras do catálogo.
Pontos para observar no código
  • O construtor recebe Repositorio, sem saber quem o implementará.
  • Cada operação que lê/grava usa transacao; exceções impedem confirmação parcial.
  • As validações desta etapa ocorrem antes de criar entidades ou acessar o repositório.

// Finalidade: Coordenar os casos de uso do restaurante pela porta Repositorio.
package br.edu.soa.restaurante.aplicacao;

import br.edu.soa.restaurante.dominio.*;
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.net.URI;
import java.util.List;
import java.util.function.Function;

/** Casos de uso. O transporte não fornece total, preço de item nem situação do pedido. */
public final class Restaurante {
    private final Repositorio repositorio;

    public Restaurante(Repositorio repositorio) { this.repositorio = repositorio; }

    // Consulta as mesas pela porta de persistência.
    public List<Mesa> listarMesas() { return repositorio.transacao(Repositorio.Sessao::mesas); }
    // Obtém uma mesa identificada pelo ID.
    public Mesa consultarMesa(long id) { return repositorio.transacao(s -> s.mesa(id, false)); }
    // Valida o cadastro e impede alterar uma mesa ocupada.
    public Mesa salvarMesa(long id, int numero) {
        if (id < 0 || numero < 1 || numero > 9999) throw Falha.invalido("Número da mesa entre 1 e 9999; ID não negativo.");
        return repositorio.transacao(s -> {
            if (id > 0 && s.mesa(id, true).situacao() == SituacaoMesa.OCUPADA)
                throw Falha.conflito("MESA_OCUPADA", "Libere a mesa antes de alterar seu número.");
            return s.salvarMesa(id, numero);
        });
    }
    // Confere a situação da mesa antes de solicitar a exclusão.
    public void excluirMesa(long id) {
        repositorio.transacao(s -> {
            if (s.mesa(id, true).situacao() == SituacaoMesa.OCUPADA)
                throw Falha.conflito("MESA_OCUPADA", "Mesa possui pedido aberto.");
            s.excluirMesa(id); return null;
        });
    }
    // Consulta o catálogo de categorias.
    public List<Categoria> listarCategorias() { return repositorio.transacao(Repositorio.Sessao::categorias); }
    public Categoria consultarCategoria(long id) { return repositorio.transacao(s -> s.categoria(id)); }
    // Valida os textos e coordena o cadastro da categoria.
    public Categoria salvarCategoria(long id, String nome, String descricao, boolean ativo) {
        if (id < 0) throw Falha.invalido("ID não negativo.");
        Categoria c = new Categoria(id, texto(nome, "Nome", 120), opcional(descricao, 2000), ativo);
        return repositorio.transacao(s -> { if (id > 0) s.categoria(id); return s.salvarCategoria(c); });
    }
    // Solicita a exclusão; vínculos existentes serão protegidos pela persistência.
    public void excluirCategoria(long id) {
        repositorio.transacao(s -> { s.categoria(id); s.excluirCategoria(id); return null; });
    }
    private static String texto(String s, String nome, int limite) {
        if (s == null || s.isBlank() || s.length() > limite) throw Falha.invalido(nome + " obrigatório, limite de " + limite + " caracteres.");
        return s.trim();
    }
    private static String opcional(String s, int limite) {
        if (s == null) return "";
        if (s.length() > limite) throw Falha.invalido("Texto excede " + limite + " caracteres.");
        return s.trim();
    }
}

Entenda cada parte de Restaurante.java

Módulo aplicacao · Pacote br.edu.soa.restaurante.aplicacao · Fontes src/main/java.

Parte O que faz e por que importa
listarCategorias e consultarCategoria Separam a leitura da coleção da busca de um registro por ID. Ambas passam pela sessão do repositório.
salvarCategoria Monta uma Categoria com nome, descrição e indicador de atividade. Na atualização, confere que o ID já existe antes de salvar.
texto e opcional texto exige preenchimento, confere o limite e remove espaços das extremidades. opcional transforma ausência em texto vazio e confere o tamanho.
ativo Registra se a categoria pode participar do catálogo. Uma alteração desse campo preserva o identificador que os produtos referenciam.
excluirCategoria Consulta o registro antes de pedir a exclusão. O banco aplicará as restrições de vínculo quando a infraestrutura estiver pronta.
