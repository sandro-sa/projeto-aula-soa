2. Entenda o que será feito

Pedido representa a conta de uma mesa. List.copyOf guarda uma cópia não modificável da lista recebida; total() soma os subtotais dos itens a partir de 0.00.

  • O enum SituacaoPedido e o record ItemPedido já existem.
  • O record mantém os dados; as transições de estado serão coordenadas pela aplicação.
Pontos para observar no código
  • mesaId associa a conta; dataHora é um Instant UTC; situacao usa o enum.
  • O construtor copia itens com List.copyOf, impedindo mutação da lista por fora.
  • total() soma os subtotais no servidor, começando em 0.00.

// Finalidade: Representar a conta de uma mesa e calcular seu total pelos itens.
package br.edu.soa.restaurante.dominio;
import java.math.BigDecimal;
import java.time.Instant;
import java.util.List;
public record Pedido(long id, long mesaId, Instant dataHora, SituacaoPedido situacao, List<ItemPedido> itens) {
 // Copia a lista recebida para impedir mudanças externas na coleção do pedido.
 public Pedido { itens = List.copyOf(itens); }
 // Soma os subtotais dos itens com BigDecimal, partindo de zero.
 public BigDecimal total() { return itens.stream().map(ItemPedido::subtotal).reduce(new BigDecimal("0.00"), BigDecimal::add); }
}

Confira: o arquivo pertence ao projeto dominio, no caminho indicado e com o conteúdo completo desta etapa.

Fundamentação e leitura complementar

Fundamentação nos PDFs fornecidos

Pedido reúne dados e comportamento do negócio: total é derivado dos itens e dataHora identifica um instante. A leitura de java.time diferencia data local de data com fuso; a escolha de Instant/UTC é explicitada no código desta trilha.

  • [R03] Robert C. Martin — Arquitetura Limpa: o guia do artesão para estrutura e design de software. Cap. 20: entidades, casos de uso e modelos de dados. Páginas 260–266 do PDF.
  • [R05] Paulo Silveira; Rodrigo Turini — Java 8 Prático: lambdas, streams e os novos recursos da linguagem. Cap. 11, §11.2–11.3: soma de BigDecimal por redução. Páginas 110–112 do PDF.
  • [R05] Paulo Silveira; Rodrigo Turini — Java 8 Prático: lambdas, streams e os novos recursos da linguagem. Cap. 10, §10.2: java.time e imutabilidade. Páginas 93–96 do PDF.
