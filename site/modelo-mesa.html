Implementar Mesa

Representar uma mesa usando o enum criado na aula 13.

1. O que fazer nesta etapa

Sua tarefa é criar um único arquivo: Mesa.java.

No Eclipse, use o projeto dominio e o pacote br.edu.soa.restaurante.dominio, já existentes. O código completo e comentado está no passo 2.

A aula termina quando o arquivo aparecer nesse pacote e a compilação Maven mostrar BUILD SUCCESS na aba Console.

Continue o projeto após Criar o módulo domínio e seus estados. O novo arquivo ficará em source/restaurante-soap/dominio/src/main/java/br/edu/soa/restaurante/dominio/Mesa.java.

2. Entenda os dados de Mesa

Uma mesa precisa de uma identificação técnica, de um número usado no salão e de uma situação. Vamos reunir esses três dados em um record Java.

Componentes do record Mesa
Componente Tipo Função Exemplo
id long Identificador técnico do registro, usado para consultar ou relacionar a mesa. 7
numero int Número que o funcionário vê no salão. Pode ser diferente do id. 3
situacao SituacaoMesa Valor do enum já criado: LIVRE ou OCUPADA. SituacaoMesa.LIVRE

Um record declara seus componentes no cabeçalho. O Java gera o construtor e os métodos de leitura id(), numero() e situacao(), além de equals(), hashCode() e toString(). Os campos são final, sem setters. Referência: records em Java.

Exemplo: uma mesa pode ter id = 7 e numero = 3. A regra que impede dois pedidos abertos na mesma mesa será implementada na aplicação; este record representa seus dados.

3. Faça o passo a passo no Eclipse

Passo 1: Criar o arquivo no pacote existente

  1. No Project Explorer, expanda dominio → src/main/java → br.edu.soa.restaurante.dominio.
  2. Selecione o pacote e acesse File → New → Other… → General → File → Next.
  3. Confira a pasta de destino: dominio/src/main/java/br/edu/soa/restaurante/dominio.
  4. Em File name, informe Mesa.java e clique em Finish.

Confira: o Eclipse abriu Mesa.java no pacote do domínio. Se ele já existir, abra esse arquivo e compare seu conteúdo com o passo seguinte.

Passo 2: Escrever o record comentado

Cole o código completo abaixo no editor de Mesa.java e salve com Ctrl+S. Os comentários explicam cada parte e podem ser mantidos no arquivo.

package br.edu.soa.restaurante.dominio;

// Record: reúne os dados de uma mesa e gera construtor e acessores.
public record Mesa(
    // Identificação técnica do registro.
    long id,
    // Número da mesa mostrado aos funcionários.
    int numero,
    // Usa o enum LIVRE/OCUPADA criado na aula 13.
    SituacaoMesa situacao
) {}

Confira: A declaração usa record, o tipo da situação é SituacaoMesa e o enum continua no mesmo pacote.

Passo 3: Compilar pelo Maven no Eclipse

  1. Use File → Save All.
  2. Acesse Run → Run Configurations… → Maven Build e selecione Compilar dominio, a configuração da aula 13.
  3. Confira Base directory: deve apontar para o projeto dominio, em source/restaurante-soap/dominio.
  4. Em Goals, mantenha o conteúdo abaixo. Confira o JDK 17 na aba JRE e clique em Run.
compile

Deu certo quando: a aba Console terminar com BUILD SUCCESS. O Maven compila os fontes do módulo e gera Mesa.class em dominio/target/classes/br/edu/soa/restaurante/dominio.

Passo 4: Conferir o resultado na IDE

  1. No Project Explorer, confira Mesa.java junto aos tipos das aulas anteriores.
  2. Abra a aba Problems e confira se há erros relacionados ao projeto dominio. Se necessário, use Window → Show View → Problems.
  3. Compare o conteúdo salvo com o código desta aula e confira o BUILD SUCCESS da execução Maven.

Se algo não funcionar no Eclipse
  • O arquivo está fora do pacote: confira a pasta selecionada no assistente File e a declaração package br.edu.soa.restaurante.dominio;.
  • Erro no nome do tipo: o arquivo deve se chamar Mesa.java e declarar public record Mesa, respeitando maiúsculas.
  • record não é reconhecido: confira o JDK 17 e use Maven → Update Project… no projeto dominio.
  • A configuração de execução não aparece: clique com o botão direito em dominio → Run As → Maven build…, use o nome Compilar dominio e informe compile em Goals.
  • SituacaoMesa não é encontrado: confira se o enum da aula 13 está no mesmo pacote e se o nome foi escrito com as mesmas maiúsculas.

5. Confira e continue

  • Salvei Mesa.java no projeto dominio e no pacote correto.
  • Consigo diferenciar id de numero e explicar o uso de SituacaoMesa.
  • A aba Problems está sem erros referentes ao módulo.
  • A compilação Maven terminou com BUILD SUCCESS.

Depois, avance para Implementar Categoria.
