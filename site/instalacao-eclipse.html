Instalar Eclipse e registrar o JDK

Preparar a IDE para Maven, Java 17 e publicação WAR.

1. Objetivo do tutorial

Preparar a IDE para Maven, Java 17 e publicação WAR.

2. Conceitos necessários

O pacote Enterprise agrega ferramentas Java/Web e adaptadores de servidores. WTP fornece essas integrações.

Instale Eclipse IDE for Enterprise Java and Web Developers. Se usar Java Developers, instale Eclipse Java Web Developer Tools e adaptadores Tomcat pelo repositório da própria release, em Help → Install New Software. Reinicie e confira a visualização Servers.

Em Window → Preferences → Java → Installed JREs, registre o JDK 17; associe JavaSE-17 em Execution Environments. Neste momento não importe um projeto existente: ele será criado nos próximos tutoriais. Abra um workspace separado da pasta dos arquivos do laboratorio-restaurante-soa.

3. Problema que será resolvido

Eclipse Java Developers pode não oferecer a visualização Servers nem o adaptador Tomcat.

4. Arquivos a criar ou alterar

Caminhos relativos à pasta vazia do laboratorio-restaurante-soa, e depois ao projeto que você está construindo:

Este tutorial configura ferramentas ou exercita o projeto já construído. Nenhuma classe futura é pressuposta.

Execute os passos na ordem apresentada. Não há arquivo de solução para importar no início. Quando um arquivo evolui, a versão completa abaixo corresponde exatamente a esta etapa.

6. Explicação do código e das decisões

  • File → Import → Maven → Existing Maven Projects lê a relação dos POMs.
  • Maven → Update Project atualiza classpath e diretórios gerados.
  • Run As → Java Application serve para Swing ou Spring Boot; o endpoint Metro precisa de publicação no Tomcat.

7. Como implementar no Eclipse e executar

  1. Continue na pasta do laboratorio-restaurante-soa criada no tutorial inicial. Conclua Instalar e configurar o JDK 17 antes desta etapa.
  2. Execute a configuração/experimento descrito acima e registre o resultado.
  3. Execute somente os comandos desta página. Use outro terminal quando um comando mantiver um servidor em execução.
java -version

8. Fluxo da execução

IDE Enterprise/WTP → m2e → projetos Maven → WAR → adaptador Tomcat.

9. Resultado esperado nesta etapa

IDE preparada, ainda sem projetos do restaurante.

O resultado é um checkpoint para você executar. O registro de validação do material distingue testes automatizados, reconstrução da trilha e execução real no MySQL. Consulte também a revisão passo a passo dos HTMLs.

10. Problemas frequentes

  • Erro de pacote: compare a declaração package com a pasta src/main/java.
  • Dependência não resolvida: confirme o POM e o módulo criados nesta etapa; não copie JARs manualmente.
  • Não execute um tutorial posterior para compensar um erro: retorne ao último checkpoint aprovado.

11. Checkpoint antes de continuar

  • Registrar JDK 17 e manter a pasta do laboratorio-restaurante-soa sem fontes.
