2. Entenda o que será feito

Problema no sistema

As regras podem funcionar com um repositório simulado e ainda falhar ao gravar, reverter ou disputar uma mesa no banco. A suíte separa a integração SQL, a classificação de erros e a verificação opcional com o MySQL local.

Os cenários verificam transações, histórico e concorrência com H2 e classificam os códigos de erro MySQL.

  • MySqlLocalTest é opt-in: exige MYSQL_TEST_URL para restaurante_teste em localhost, MYSQL_TEST_USER e MYSQL_TEST_PASSWORD.
  • Para habilitá-lo, configure essas variáveis na aba Environment da execução Maven e use um banco de teste preparado.
  • H2 em modo MySQL não comprova uma execução no servidor MySQL real.
Pontos para observar no código
  • Os 18 testes comportamentais usam bancos H2 independentes por teste.
  • ErrosMySqlTest verifica códigos específicos mesmo quando SQLState é igual.
  • MySqlLocalTest faz uma conta de 110,00 no banco real e a relê por outro repositório; depende de configuração explícita.

    // Cenário: distingue duplicado de chave estrangeira no mesmo sql state.

        assertEquals("DUPLICADO",JdbcRepositorio.falhaSql(new SQLException("Detalhe privado","23000",1062)).codigo());
        for (int codigo : new int[]{1451,1452})
            assertEquals("REFERENCIADO",JdbcRepositorio.falhaSql(new SQLException("Detalhe privado","23000",codigo)).codigo());
    }
    // Cenário: lock timeout edeadlock pedem nova tentativa.
    @Test void lockTimeoutEDeadlockPedemNovaTentativa() {
        for (int codigo : new int[]{1205,1213})
            assertEquals("CONCORRENCIA",JdbcRepositorio.falhaSql(new SQLException("Detalhe privado","HY000",codigo)).codigo());
    }
}

package br.edu.soa.restaurante.infraestrutura;

import br.edu.soa.restaurante.aplicacao.Restaurante;
import java.math.BigDecimal;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.condition.EnabledIfEnvironmentVariable;
import static org.junit.jupiter.api.Assertions.*;

/** Opt-in: usa apenas banco de teste explícito no MySQL localhost. Não apaga tabelas. */
@EnabledIfEnvironmentVariable(named="MYSQL_TEST_URL",matches="jdbc:mysql://localhost:(?:3306|13306)/restaurante_teste(?:\\?.*)?")
class MySqlLocalTest {
    // Cenário: persiste conta no my sql real.
    @Test void persisteContaNoMySqlReal() {
        var ds=Banco.configurar(System.getenv("MYSQL_TEST_URL"),System.getenv("MYSQL_TEST_USER"),System.getenv("MYSQL_TEST_PASSWORD"));
        var api=new Restaurante(new JdbcRepositorio(ds));
        var usados=api.listarMesas().stream().map(m -> m.numero()).collect(java.util.stream.Collectors.toSet());
        int numero=java.util.stream.IntStream.range(1000,10000).filter(n -> !usados.contains(n)).findFirst().orElseThrow();
        var mesa=api.salvarMesa(0,numero);
        var cat=api.salvarCategoria(0,"Teste MySQL","Dados de integração",true);
        var produto=api.salvarProduto(0,cat.id(),"Carbonara de teste","","",new BigDecimal("55.00"),"1 pessoa",true);
        var pedido=api.adicionarItem(api.abrirPedido(mesa.id()).id(),produto.id(),2);
        assertEquals(new BigDecimal("110.00"),pedido.total());
        api.fecharPedido(pedido.id());
        var outraInstancia=new Restaurante(new JdbcRepositorio(ds));
        assertEquals(new BigDecimal("110.00"),outraInstancia.consultarPedido(pedido.id()).total());
        assertEquals(br.edu.soa.restaurante.dominio.SituacaoMesa.LIVRE,outraInstancia.consultarMesa(mesa.id()).situacao());
    }
}

Fundamentação nos PDFs fornecidos

Teste as consequências de concorrência e falhas transacionais, não apenas métodos isolados. O comportamento em H2 e o comportamento no MySQL real são evidências distintas; um teste opt-in ignorado não prova a segunda.

  • [R03] Robert C. Martin — Arquitetura Limpa: o guia do artesão para estrutura e design de software. Cap. 28: o limite teste e testabilidade. Páginas 323–327 do PDF.
  • [R08] Hébert Coelho — JPA Eficaz: as melhores práticas de persistência de dados em Java. Cap. 8, §8.4: versionamento e locks. Páginas 159–164 do PDF.
