Criar os primeiros POMs do zero

Criar a configuração inicial do projeto e abri-la no Eclipse.

1. O que fazer nesta etapa

Sua tarefa é criar três arquivos na pasta laboratorio-restaurante-soa:

  1. pom.xml
  2. source/restaurante-soap/pom.xml
  3. scripts/maven.ps1

Depois, valide os dois POMs e importe os projetos no Eclipse. A aula termina quando os dois comandos mostrarem BUILD SUCCESS e os projetos aparecerem na IDE.

Continue na pasta usada na aula 11. Os documentos anteriores permanecem nela. A criação das classes começa na aula 13.

Os módulos precisam ser construídos com as mesmas opções de Java e com dependências compatíveis entre etapas. Os dois POMs distribuem essas responsabilidades e o script facilita iniciar o Maven na raiz.

Passo 4: Criar scripts/maven.ps1

Abra o arquivo do script:

notepad '.\scripts\maven.ps1'

Copie o conteúdo completo, incluindo os comentários numerados, e salve. Cada comentário explica uma etapa do script:

# 1. Recebe os argumentos escritos depois do nome do script.
# Exemplo: -N validate. As opções são repassadas ao Maven.
$argumentosMaven = @($args)

# 2. Se nenhum argumento foi informado, usa clean verify.
# clean limpa arquivos gerados; verify percorre o build e suas verificações.
if ($argumentosMaven.Count -eq 0) { $argumentosMaven = @('clean','verify') }

# 3. Interrompe o script se um comando do PowerShell gerar erro.
# O código de saída do Maven será conferido separadamente no passo 7.
$ErrorActionPreference = 'Stop'

# 4. Localiza a raiz do laboratório.
# PSScriptRoot é a pasta scripts; Split-Path -Parent obtém a pasta acima.
$raiz = Split-Path -Parent $PSScriptRoot

# 5. Guarda a pasta atual do terminal e entra na raiz do laboratório.
Push-Location -LiteralPath $raiz
try {
    # 6. Executa o Maven a partir da raiz.
    # & chama o comando mvn.
    # -Dmaven.repo.local escolhe onde guardar bibliotecas e plugins baixados.
    # @argumentosMaven repassa cada argumento como uma opção separada.
    & mvn "-Dmaven.repo.local=$raiz\.m2\repository" @argumentosMaven

    # 7. Confere se o Maven terminou com sucesso: código zero.
    # Um código diferente de zero gera um erro no script.
    if ($LASTEXITCODE -ne 0) { throw "Maven terminou com código $LASTEXITCODE" }
} finally {
    # 8. Ao sair do bloco try, retorna à pasta anterior, mesmo em caso de erro.
    Pop-Location
}

Confira: o nome deve ser maven.ps1, sem .txt no final. O script encaminha comandos ao Maven; a validação desta aula será feita diretamente com mvn, no passo seguinte.

Passo 5: Validar os dois POMs

Salve os três arquivos. No PowerShell, ainda na raiz do laboratório, execute primeiro:

mvn -N validate

Confira: deve aparecer BUILD SUCCESS. Esse comando valida o POM da raiz.

Depois, execute:

mvn -f source/restaurante-soap/pom.xml -N validate

Confira: deve aparecer outro BUILD SUCCESS. Agora o Maven validou o POM de restaurante-soap. Na primeira execução, ele pode baixar os arquivos necessários; aguarde o resultado final.

-f escolhe o POM; -N limita a execução ao projeto selecionado. validate verifica a configuração antes das fases de compilação e testes. Consulte, se precisar, as opções do Maven e o ciclo de execução.

Se a validação ou a importação não der certo
  • Maven não encontra o POM: confira Get-Location e o nome do arquivo. Ele deve terminar em .xml, sem .txt.
  • Erro ao ler XML: compare o arquivo com o bloco completo do passo correspondente, incluindo as tags de abertura e fechamento.
  • Módulo não encontrado: o POM da raiz lista apenas source/restaurante-soap; o bloco modules do POM SOAP deve estar vazio.
  • Falha ao baixar dependências: confira a conexão com a Internet e repita o comando que falhou.
  • mvn não é reconhecido: retome a configuração do Maven e abra um terminal novo.
  • Eclipse não encontra os projetos: escolha a pasta do laboratório como Root Directory e confira se os dois POMs foram salvos.

5. Confira e continue

  • Mantive diagramas/componentes.md e docs/camadas.md nos diretórios das aulas anteriores.
  • Salvei os três arquivos nos caminhos indicados.
  • O bloco modules do POM restaurante-soap está vazio.
  • Os dois comandos de validação mostraram BUILD SUCCESS.
  • Os dois projetos aparecem no Eclipse.

Depois, avance para Criar o módulo domínio e seus estados.
