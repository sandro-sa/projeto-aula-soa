  2. Atualizar: pom.xml

Continue no Eclipse após Escrever o primeiro endpoint HTTP. Use os projetos e os arquivos que você construiu nas etapas anteriores.

2. Entenda o que será feito

Problema no sistema

A API REST precisa executar as mesmas regras e acessar a mesma implementação de persistência já construídas. A raiz passa a construir os dois projetos, e o POM REST declara o núcleo e as integrações HTTP de que precisa.

Entenda os componentes desta etapa
ParteO que faz e por que importa
parent RESTO Spring Boot 4.1.2 permanece como pai da aplicação REST. O POM raiz a inclui por agregação.
infraestrutura 2.0.0É um módulo do próprio laboratório. A execução Maven da raiz inclui os projetos locais usados pela API.
springdoc e segurançaAcrescentam a geração da documentação das rotas e a cadeia de autorização. O código dessas integrações virá nas etapas seguintes.
cardapio-webO POM REST incorpora os arquivos compartilhados na pasta estática do aplicativo.

O REST reutiliza os artefatos do núcleo e configura segurança e documentação sem depender do contrato SOAP.

  • Preserve o parent Spring Boot 4.1.2 gerado pelo Initializr.
  • A versão 2.0.0 identifica o artefato do restaurante; springdoc 3.1.0 pertence à integração OpenAPI dessa linha.
Pontos para observar no código
  • O POM continua derivado do Initializr, agora com dependências do domínio.
  • As dependências test não vão para o executável.
  • O build resources compartilha o frontend já construído nas aulas anteriores.
