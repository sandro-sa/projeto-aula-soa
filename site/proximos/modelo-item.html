Implementar ItemPedido

Representar um item do pedido, validar a quantidade e calcular seu subtotal.

1. O que fazer nesta etapa

Sua tarefa é criar um único arquivo: ItemPedido.java.

No Eclipse, use o projeto dominio e o pacote br.edu.soa.restaurante.dominio, já existentes. O código completo e comentado está no passo 2.

A aula termina quando o arquivo aparecer nesse pacote e a compilação Maven mostrar BUILD SUCCESS na aba Console.

Continue o projeto após Implementar Produto. O novo arquivo ficará em source/restaurante-soap/dominio/src/main/java/br/edu/soa/restaurante/dominio/ItemPedido.java.

2. Entenda os dados de ItemPedido

Problema no sistema

O preço de um produto pode mudar após a venda. O item guarda os dados usados na inclusão e calcula seu próprio subtotal, permitindo consultar a conta pelo valor daquele momento.

Um item registra um produto incluído no pedido. Ele guarda a quantidade e os valores de nome e preço recebidos na inclusão, para preservar o histórico da conta.

Componentes do record ItemPedido
ComponenteTipoFunçãoExemplo
idlongIdentificador da inclusão no pedido.1
produtoIdlongIdentificador do produto escolhido.10
nomeProdutoStringNome guardado no momento da inclusão.Suco de laranja
quantidadeintQuantidade permitida de 1 até 10000, inclusive.2
precoUnitarioBigDecimalPreço guardado para cada unidade desse item.new BigDecimal("18.50")

Produto e item têm papéis diferentes: Produto.preco é o preço do catálogo; ItemPedido.precoUnitario guarda o preço usado naquela inclusão. A aplicação e a persistência farão a cópia desses dados ao registrar o item.

Construtor compacto: o bloco public ItemPedido { ... } valida os argumentos durante a criação do record. Se a quantidade estiver fora do intervalo, lança IllegalArgumentException. Ao concluir normalmente, o Java atribui os argumentos aos campos. Construtores de records.

Subtotal: subtotal() multiplica o preço unitário pela quantidade. Com duas unidades de 18.50, o resultado é 37.00. O cálculo usa os dados do próprio item.

Quantidade e subtotal
EntradaComportamento esperado

Passo 2: Escrever o record comentado

Cole o código completo abaixo no editor de ItemPedido.java e salve com Ctrl+S. Os comentários explicam cada parte e podem ser mantidos no arquivo.

package br.edu.soa.restaurante.dominio;

import java.math.BigDecimal;

// Dados de uma inclusão de produto em um pedido.
public record ItemPedido(
    long id,
    long produtoId,
    // Nome recebido no momento da inclusão, para preservar o histórico.
    String nomeProduto,
    int quantidade,
    // Preço recebido na inclusão, independente de mudanças no catálogo.
    BigDecimal precoUnitario
) {
    // Construtor compacto: valida os argumentos antes de guardar os campos.
    public ItemPedido {
        // Aceita quantidades de 1 até 10000, inclusive.
        if (quantidade <= 0 || quantidade > 10000)
            throw new IllegalArgumentException("Quantidade entre 1 e 10000.");
    }

    // Calcula o valor desse item: preço unitário multiplicado pela quantidade.
    public BigDecimal subtotal() {
        // Converte a quantidade inteira para BigDecimal antes de multiplicar.
        return precoUnitario.multiply(BigDecimal.valueOf(quantidade));
    }
}

Confira: A validação fica no bloco public ItemPedido. O método subtotal() retorna BigDecimal e usa precoUnitario e quantidade.

Se algo não funcionar no Eclipse
  • O arquivo está fora do pacote: confira a pasta selecionada no assistente File e a declaração package br.edu.soa.restaurante.dominio;.
  • Erro no nome do tipo: o arquivo deve se chamar ItemPedido.java e declarar public record ItemPedido, respeitando maiúsculas.
  • record não é reconhecido: confira o JDK 17 e use Maven → Update Project… no projeto dominio.
  • A configuração de execução não aparece: clique com o botão direito em dominio → Run As → Maven build…, use o nome Compilar dominio e informe compile em Goals.
  • Erro no construtor compacto: confira public ItemPedido { ... }, sem parênteses ou tipo de retorno, dentro do corpo do record.
