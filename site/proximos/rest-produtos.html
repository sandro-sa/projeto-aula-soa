2. Entenda o que será feito

Problema no sistema

O consumidor REST precisa achar produtos por nome e categoria e cadastrar preços com o formato esperado. ProdutoController prepara essas entradas e mantém a validação de negócio compartilhada com SOAP.

O controller de produto traduz a entrada HTTP, valida o DTO e mapeia a saída. As regras e transações permanecem em Restaurante.

  • Confira os métodos HTTP e as rotas declaradas no próprio código: cadastro, consulta, atualização e exclusão.
  • As anotações de documentação descrevem as operações; não executam as regras.
Pontos para observar no código
  • @Valid verifica os campos do DTO antes da chamada do caso de uso.
  • Saidas mapeia a entidade recebida para o contrato JSON.
  • @Operation/@ApiResponse descrevem os endpoints para a aula OpenAPI, sem implementar a regra.

// Finalidade: Adaptar as operações HTTP aos casos de uso e às respostas da API.
package br.edu.soa.restaurante.rest;
import br.edu.soa.restaurante.aplicacao.Restaurante;
import br.edu.soa.restaurante.aplicacao.Falha;
import org.springframework.web.bind.annotation.*;
import org.springframework.http.ResponseEntity;
import jakarta.validation.Valid;
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.responses.*;
import io.swagger.v3.oas.annotations.media.*;
import java.util.List;
import java.net.URI;
@RestController @RequestMapping(value="/api/produtos",produces="application/json")
@ApiResponses({@ApiResponse(responseCode="400",description="Entrada inválida",content=@Content(mediaType="application/json",schema=@Schema(implementation=Erros.Erro.class))),@ApiResponse(responseCode="401",description="Não autenticado",content=@Content(mediaType="application/json",schema=@Schema(implementation=Erros.Erro.class))),@ApiResponse(responseCode="403",description="Sem permissão",content=@Content(mediaType="application/json",schema=@Schema(implementation=Erros.Erro.class))),@ApiResponse(responseCode="404",description="Não encontrado",content=@Content(mediaType="application/json",schema=@Schema(implementation=Erros.Erro.class))),@ApiResponse(responseCode="409",description="Duplicado ou registro referenciado",content=@Content(mediaType="application/json",schema=@Schema(implementation=Erros.Erro.class))),@ApiResponse(responseCode="503",description="Banco indisponível",content=@Content(mediaType="application/json",schema=@Schema(implementation=Erros.Erro.class)))})
public class ProdutoController {
 private final Restaurante api;
 public ProdutoController(Restaurante api) { this.api=api; }
 @GetMapping @Operation(summary="Listar produtos com paginação e pesquisa") @ApiResponse(responseCode="200",description="Operação realizada")
 public List<Saidas.ProdutoDto> listar(@RequestParam(defaultValue="0") int offset,@RequestParam(defaultValue="50") int limite,@RequestParam(defaultValue="") String busca,@RequestParam(required=false) Long categoriaId) {
  if(offset<0 || limite<1 || limite>100 || busca.length()>160) throw Falha.invalido("Offset não negativo, limite entre 1 e 100 e busca até 160 caracteres.");
  return api.listarProdutos().stream().filter(v -> v.nome().toLowerCase(java.util.Locale.ROOT).contains(busca.toLowerCase(java.util.Locale.ROOT))).filter(v -> categoriaId==null || v.categoriaId()==categoriaId).skip(offset).limit(limite).map(Saidas::dto).toList();
 }
 @GetMapping("/{id}") @Operation(summary="Consultar produto por ID") @ApiResponse(responseCode="200",description="Operação realizada")
 public Saidas.ProdutoDto consultar(@PathVariable long id) { return Saidas.dto(api.consultarProduto(id)); }
 @PostMapping(consumes="application/json") @Operation(summary="Cadastrar produto — ADMIN") @ApiResponse(responseCode="201",description="Criado; Location contém URL")
 public ResponseEntity<Saidas.ProdutoDto> criar(@Valid @RequestBody Entradas.Produto v) { var salvo=api.salvarProduto(0,v.categoriaId(),v.nome(),v.descricao(),v.imagem(),v.preco(),v.porcao(),v.disponivel()); return ResponseEntity.created(URI.create("/api/produtos/"+salvo.id())).body(Saidas.dto(salvo)); }
 @PutMapping(value="/{id}",consumes="application/json") @Operation(summary="Substituir cadastro — ADMIN; situação controlada pelo servidor") @ApiResponse(responseCode="200",description="Operação realizada")
 public Saidas.ProdutoDto atualizar(@PathVariable long id,@Valid @RequestBody Entradas.Produto v) { if(id<1) throw Falha.invalido("ID positivo obrigatório."); return Saidas.dto(api.salvarProduto(id,v.categoriaId(),v.nome(),v.descricao(),v.imagem(),v.preco(),v.porcao(),v.disponivel())); }
 @DeleteMapping("/{id}") @ResponseStatus(org.springframework.http.HttpStatus.NO_CONTENT) @Operation(summary="Excluir sem vínculos — ADMIN; use desativação quando referenciado") @ApiResponse(responseCode="204",description="Excluído")
 public void excluir(@PathVariable long id) { api.excluirProduto(id); }
}

Entenda cada parte de ProdutoController.java

Módulo restaurante-rest-openapi · Pacote br.edu.soa.restaurante.rest · Fontes src/main/java.

ParteO que faz e por que importa
@RestController, @RequestMapping e construtorRegistram /api/produtos e recebem o bean Restaurante para executar os casos de uso.
GET, offset, limite e buscaEscolhe a leitura geral ou por categoriaId e aplica pesquisa e paginação aos produtos encontrados.
GET /{id} e @PathVariableObtêm o identificador da URL e transformam o registro consultado em DTO de resposta.
POST, @Valid e LocationEntradas.Produto fornece categoria, descrição, imagem, preço, porção e disponibilidade para o cadastro. A criação retorna 201 e o endereço do novo recurso.
PUT /{id}Exige ID positivo e um corpo validado. Envia a atualização ao núcleo e devolve a representação atual.
DELETE /{id} e 204Pede a exclusão ao núcleo e devolve 204 no sucesso. Restrições de vínculo podem gerar conflito.
@Operation e @ApiResponseDocumentam intenção, status e formato das respostas no OpenAPI. A execução passa pelas rotas e pelas regras já implementadas.
