Implementar Produto

Representar os dados de um produto, incluindo categoria, preço e disponibilidade.

1. O que fazer nesta etapa

Sua tarefa é criar um único arquivo: Produto.java.

No Eclipse, use o projeto dominio e o pacote br.edu.soa.restaurante.dominio, já existentes. O código completo e comentado está no passo 2.

A aula termina quando o arquivo aparecer nesse pacote e a compilação Maven mostrar BUILD SUCCESS na aba Console.

Continue o projeto após Implementar Categoria. O novo arquivo ficará em source/restaurante-soap/dominio/src/main/java/br/edu/soa/restaurante/dominio/Produto.java.

2. Entenda os dados de Produto

Problema no sistema

O restaurante precisa cadastrar o que vende, em qual grupo aparece e por quanto será oferecido. Produto reúne a identidade, a apresentação e as informações usadas nas próximas inclusões em pedidos.

O produto é o item oferecido no cardápio. Ele guarda a identificação de sua categoria, os textos de apresentação e o preço que será usado nas novas inclusões em pedidos.

Componentes do record Produto
ComponenteTipoFunçãoExemplo
idlongIdentificador técnico do produto.10
categoriaIdlongIdentificador da categoria à qual ele pertence.2
nomeStringNome apresentado no cardápio.Suco de laranja
descricaoStringTexto sobre o produto.Suco natural preparado na hora
imagemStringCaminho ou URL da imagem, interpretado pela interface.assets/suco.jpg
precoBigDecimalValor decimal do produto.new BigDecimal("18.50")
porcaoStringDescrição da porção ou do rendimento.Copo de 500 ml
disponivelbooleanIndicação usada para permitir novas inclusões.true

Preço com BigDecimal: esse tipo permite trabalhar com números decimais. Ao escrever valores no código, use texto, como new BigDecimal("18.50"), para preservar o decimal informado. Ele pertence ao JDK e será importado de java.math. Referência de BigDecimal.

Ligação com a categoria: categoriaId guarda um identificador. A aplicação vai conferir se a categoria existe e está ativa antes de salvar o produto. Este record também guarda o caminho da imagem; o carregamento visual será feito na interface.

3. Faça o passo a passo no Eclipse

Passo 1: Criar o arquivo no pacote existente

  1. No Project Explorer, expanda dominio → src/main/java → br.edu.soa.restaurante.dominio.
  2. Selecione o pacote e acesse File → New → Other… → General → File → Next.
  3. Confira a pasta de destino: dominio/src/main/java/br/edu/soa/restaurante/dominio.
  4. Em File name, informe Produto.java e clique em Finish.

Confira: o Eclipse abriu Produto.java no pacote do domínio. Se ele já existir, abra esse arquivo e compare seu conteúdo com o passo seguinte.

Passo 2: Escrever o record comentado

Cole o código completo abaixo no editor de Produto.java e salve com Ctrl+S. Os comentários explicam cada parte e podem ser mantidos no arquivo.

package br.edu.soa.restaurante.dominio;

// Tipo decimal do JDK utilizado para representar o preço.
import java.math.BigDecimal;

// Dados de um produto oferecido no cardápio.
public record Produto(
    // Identificação técnica do produto.
    long id,
    // Identificação da categoria à qual o produto pertence.
    long categoriaId,
    String nome,
    String descricao,
    // Caminho ou URL que a interface usará para apresentar a imagem.
    String imagem,
    // Valor decimal usado nas novas inclusões em pedidos.
    BigDecimal preco,
    // Por exemplo: Copo de 500 ml ou Serve duas pessoas.
    String porcao,
    // Indicação considerada pela aplicação ao incluir o produto.
    boolean disponivel
) {}

Confira: O import java.math.BigDecimal; fica entre package e public record. O tipo de preco é BigDecimal.

Entenda cada parte de Produto.java

ParteO que faz e por que importa

Passo 3: Compilar pelo Maven no Eclipse

  1. Use File → Save All.
  2. Acesse Run → Run Configurations… → Maven Build e selecione Compilar dominio, a configuração da aula 13.
  3. Confira Base directory: deve apontar para o projeto dominio, em source/restaurante-soap/dominio.
  4. Em Goals, mantenha o conteúdo abaixo. Confira o JDK 17 na aba JRE e clique em Run.
compile

Deu certo quando: a aba Console terminar com BUILD SUCCESS. O Maven compila os fontes do módulo e gera Produto.class em dominio/target/classes/br/edu/soa/restaurante/dominio.

Passo 4: Conferir o resultado na IDE

  1. No Project Explorer, confira Produto.java junto aos tipos das aulas anteriores.
  2. Abra a aba Problems e confira se há erros relacionados ao projeto dominio. Se necessário, use Window → Show View → Problems.
  3. Compare o conteúdo salvo com o código desta aula e confira o BUILD SUCCESS da execução Maven.

Se algo não funcionar no Eclipse
  • O arquivo está fora do pacote: confira a pasta selecionada no assistente File e a declaração package br.edu.soa.restaurante.dominio;.
  • Erro no nome do tipo: o arquivo deve se chamar Produto.java e declarar public record Produto, respeitando maiúsculas.
  • record não é reconhecido: confira o JDK 17 e use Maven → Update Project… no projeto dominio.
  • A configuração de execução não aparece: clique com o botão direito em dominio → Run As → Maven build…, use o nome Compilar dominio e informe compile em Goals.
  • BigDecimal não é encontrado: confira o import java.math.BigDecimal; e salve o arquivo. Esse tipo já faz parte do Java.
