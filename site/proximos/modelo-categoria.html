Implementar Categoria

Criar o tipo que organiza os produtos do cardápio em categorias.

1. O que fazer nesta etapa

Sua tarefa é criar um único arquivo: Categoria.java.

No Eclipse, use o projeto dominio e o pacote br.edu.soa.restaurante.dominio, já existentes. O código completo e comentado está no passo 2.

A aula termina quando o arquivo aparecer nesse pacote e a compilação Maven mostrar BUILD SUCCESS na aba Console.

Continue o projeto após Implementar Mesa. O novo arquivo ficará em source/restaurante-soap/dominio/src/main/java/br/edu/soa/restaurante/dominio/Categoria.java.

2. Entenda os dados de Categoria

Problema no sistema

O cardápio precisa agrupar produtos por nome de categoria e permitir controlar quais grupos aparecem na consulta pública. Categoria reúne os dados necessários para esse vínculo.

Categorias agrupam produtos, como “Bebidas” e “Sobremesas”. O record Categoria vai guardar os dados desse agrupamento e a indicação de que ele está ativo.

Componentes do record Categoria
ComponenteTipoFunçãoExemplo
idlongIdentificador técnico da categoria.2
nomeStringNome que identifica o grupo no cardápio.Bebidas
descricaoStringTexto que explica o agrupamento.Sucos, águas e refrigerantes
ativobooleanIndica se a categoria está ativa.true

Como em Mesa, os componentes geram métodos de leitura: id(), nome(), descricao() e ativo(). Para o booleano, o nome do acessor é ativo().

Ativa ou inativa: o campo guarda a informação; a aplicação usará essa indicação ao montar o cardápio e permitir cadastros. Desativar uma categoria preserva sua identificação para o histórico. As consultas e validações serão implementadas nas próximas etapas.

3. Faça o passo a passo no Eclipse

Passo 1: Criar o arquivo no pacote existente

  1. No Project Explorer, expanda dominio → src/main/java → br.edu.soa.restaurante.dominio.
  2. Selecione o pacote e acesse File → New → Other… → General → File → Next.
  3. Confira a pasta de destino: dominio/src/main/java/br/edu/soa/restaurante/dominio.
  4. Em File name, informe Categoria.java e clique em Finish.

Confira: o Eclipse abriu Categoria.java no pacote do domínio. Se ele já existir, abra esse arquivo e compare seu conteúdo com o passo seguinte.

Passo 2: Escrever o record comentado

Cole o código completo abaixo no editor de Categoria.java e salve com Ctrl+S. Os comentários explicam cada parte e podem ser mantidos no arquivo.

package br.edu.soa.restaurante.dominio;

// Dados de uma categoria usada para agrupar produtos.
public record Categoria(
    // Identificação técnica da categoria.
    long id,
    // Nome do grupo, por exemplo: Bebidas.
    String nome,
    // Texto de apresentação da categoria.
    String descricao,
    // Indicação que será considerada pelas regras da aplicação.
    boolean ativo
) {}

Confira: O campo ativo é boolean; nome e descricao são String.

Entenda cada parte de Categoria.java

Módulo dominio · Pacote br.edu.soa.restaurante.dominio · Fontes src/main/java.

ParteO que faz e por que importa
record Categoria e idMantêm os componentes acessíveis por métodos gerados pelo Java. O ID é o valor que o produto usará para referenciar o grupo.
nome e descricaoApresentam o título do grupo e seu texto explicativo nas telas.
boolean ativoGuarda o estado que a aplicação usará para selecionar categorias do catálogo e verificar operações de produto.

Passo 3: Compilar pelo Maven no Eclipse

  1. Use File → Save All.
  2. Acesse Run → Run Configurations… → Maven Build e selecione Compilar dominio, a configuração da aula 13.
  3. Confira Base directory: deve apontar para o projeto dominio, em source/restaurante-soap/dominio.
  4. Em Goals, mantenha o conteúdo abaixo. Confira o JDK 17 na aba JRE e clique em Run.
compile

Deu certo quando: a aba Console terminar com BUILD SUCCESS. O Maven compila os fontes do módulo e gera Categoria.class em dominio/target/classes/br/edu/soa/restaurante/dominio.

Passo 4: Conferir o resultado na IDE

  1. No Project Explorer, confira Categoria.java junto aos tipos das aulas anteriores.
  2. Abra a aba Problems e confira se há erros relacionados ao projeto dominio. Se necessário, use Window → Show View → Problems.
  3. Compare o conteúdo salvo com o código desta aula e confira o BUILD SUCCESS da execução Maven.

Se algo não funcionar no Eclipse
  • O arquivo está fora do pacote: confira a pasta selecionada no assistente File e a declaração package br.edu.soa.restaurante.dominio;.
  • Erro no nome do tipo: o arquivo deve se chamar Categoria.java e declarar public record Categoria, respeitando maiúsculas.
  • record não é reconhecido: confira o JDK 17 e use Maven → Update Project… no projeto dominio.
  • A configuração de execução não aparece: clique com o botão direito em dominio → Run As → Maven build…, use o nome Compilar dominio e informe compile em Goals.
  • Dúvida sobre o booleano: use o tipo boolean para ativo; seus valores são true e false.

5. Confira e continue

  • Salvei Categoria.java no projeto dominio e no pacote correto.
  • Consigo explicar os quatro campos e que ativo() devolve a indicação de atividade da categoria.
  • A aba Problems está sem erros referentes ao módulo.
  • A compilação Maven terminou com BUILD SUCCESS.

Depois, avance para Implementar Produto.
