Criar o módulo domínio e seus estados

Criar o módulo domínio, seus enums e a compilação Maven dentro do Eclipse.

1. O que fazer nesta etapa

A partir desta aula, o trabalho será feito no Eclipse. Sua tarefa é criar o módulo domínio, seus dois enums e conferir o POM pai:

  1. Criar o módulo Maven dominio dentro de restaurante-soap, com seu pom.xml.
  2. Conferir a entrada dominio no bloco modules de source/restaurante-soap/pom.xml.
  3. Criar SituacaoMesa.java e SituacaoPedido.java no pacote br.edu.soa.restaurante.dominio.

A aula termina quando a aba Console mostrar BUILD SUCCESS e o projeto dominio apresentar os dois enums.

Abra o workspace usado na aula 12. No Project Explorer, os projetos laboratorio-restaurante e restaurante-soap já devem estar importados. Os arquivos continuam fisicamente na sua pasta laboratorio-restaurante-soa.

2. Entenda o que será criado

Problema no sistema

Mesa e pedido precisam ter estados conhecidos pelo compilador. O módulo dominio reúne esses tipos e se torna a base que a aplicação poderá importar para tomar decisões.

Entenda os componentes desta etapa
ParteO que faz e por que importa
módulo dominioÉ a unidade Maven que contém pom.xml e src/main/java. A execução do pai encontra o módulo pelo caminho declarado em modules.
pacote br.edu.soa.restaurante.dominioÉ o nome Java usado para organizar e importar os tipos dentro das fontes do módulo.
Properties → Resource → LocationConfirme que o módulo está na pasta dominio dentro de restaurante-soap. O nome físico é o valor que o POM pai usa para encontrar o módulo.

O módulo dominio vai guardar os tipos do negócio. Começaremos com dois enums: tipos Java que definem uma lista de valores possíveis.

Estados usados no restaurante
EnumValoresSignificado
SituacaoMesaLIVRE, OCUPADAIndica se a mesa pode receber um pedido ou já possui um pedido aberto.
SituacaoPedidoABERTO, FECHADO, CANCELADOIndica se o pedido está em andamento, foi encerrado ou cancelado.

Usar um enum permite ao compilador conferir esses valores, em vez de depender de textos digitados livremente. Nesta aula, vamos definir os estados; as regras para abrir, fechar e cancelar pedidos serão implementadas na aplicação.

POM pai e POM filho: o bloco parent faz o domínio herdar Java 17, codificação e configurações de build de restaurante-soap. Já o modules do pai inclui o domínio na execução do Maven. São relações diferentes. Consulte a referência dos POMs ou a definição de enum em Java 17.

Passo 2: Conferir o POM do módulo domínio

No projeto dominio, dê dois cliques em pom.xml. Se o editor abrir uma visão de formulário, selecione a aba pom.xml para editar o XML.

Substitua o conteúdo gerado pelo bloco completo abaixo, incluindo os comentários, e salve com Ctrl+S:

<!-- Identifica o documento como um POM Maven; o esquema auxilia o editor. -->
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
  <!-- Formato do POM, como na aula 12. -->
  <modelVersion>4.0.0</modelVersion>

  <!-- Herda a configuração do POM source/restaurante-soap/pom.xml. -->
  <parent>
    <groupId>br.edu.soa</groupId>
    <artifactId>restaurante-soap</artifactId>
    <!-- Deve corresponder à versão declarada no POM pai. -->
    <version>2.0.0</version>
  </parent>

  <!-- Nome deste módulo. groupId e version são herdados do pai. -->
  <artifactId>dominio</artifactId>
  <!-- Na fase package, o artefato deste módulo será um arquivo JAR. -->
  <packaging>jar</packaging>

  <!-- Vazio: o domínio usa apenas Java, sem bibliotecas externas. -->
  <dependencies>
  </dependencies>
</project>

Confira: parent aponta para restaurante-soap, versão 2.0.0. Por padrão, o Maven procura esse pai em ../pom.xml, uma pasta acima. O módulo se chama dominio e suas dependências ficam vazias.

Passo 4: Criar SituacaoMesa.java

Primeiro, crie o pacote Java no módulo dominio:

  1. Expanda dominio e selecione src/main/java. Se a pasta não aparecer, clique com o botão direito no projeto, escolha New → Source Folder e informe src/main/java.
  2. Clique com o botão direito em src/main/java e escolha New → Package.
  3. Em Name, digite br.edu.soa.restaurante.dominio. Mantenha Create package-info.java desmarcado e clique em Finish.

Agora, crie o enum nesse pacote:

  1. Selecione br.edu.soa.restaurante.dominio e acesse File → New → Other… → Java → Enum.
  2. Confira Source folder: dominio/src/main/java, e Package: br.edu.soa.restaurante.dominio.
  3. Em Name, informe SituacaoMesa, mantenha o modificador public e clique em Finish.

Substitua o conteúdo gerado pelo código completo abaixo e salve com Ctrl+S:

// O pacote corresponde à pasta br/edu/soa/restaurante/dominio.
package br.edu.soa.restaurante.dominio;

// Enum: define os valores possíveis para a situação de uma mesa.
public enum SituacaoMesa {
    // A mesa pode receber um novo pedido.
    LIVRE,
    // A mesa possui um pedido aberto.
    OCUPADA
}

Confira: o nome do arquivo é SituacaoMesa.java, com as mesmas maiúsculas do enum. A declaração package é br.edu.soa.restaurante.dominio.

Se a criação ou a compilação no Eclipse não der certo
  • O Maven não encontra dominio: confira a linha <module>dominio</module> no POM SOAP e a existência de dominio/pom.xml.
  • O POM pai não é encontrado: confira groupId, artifactId e versão em parent. Eles devem corresponder ao POM de restaurante-soap.
  • Erro de nome ou pacote: confira as maiúsculas de SituacaoMesa e SituacaoPedido e a linha package br.edu.soa.restaurante.dominio;.
  • src/main/java não aparece: use Maven → Update Project…. Se necessário, crie a pasta com New → Source Folder no projeto dominio.
  • Falha ao resolver a propriedade de versão do Boot: preserve <spring-boot.version>3.5.16</spring-boot.version> no POM pai. O nome deve coincidir com ${spring-boot.version}.
  • O build usa a pasta errada: na configuração Maven build, confira se Base directory aponta para dominio e se Goals contém apenas compile.
  • Java 17 não foi reconhecido: confira o JDK na aba JRE da configuração de execução e em Window → Preferences → Java → Installed JREs.
