Conferir as versões e propriedades deste POM

Os números abaixo são os adotados nesta etapa do laboratório. modelVersion descreve o formato do POM; version identifica um artefato; propriedades com nome próprio alimentam as bibliotecas e ferramentas. As explicações básicas estão na aula 12.

CampoValor desta etapa
version2.0.0
version${project.version}

dependencyManagement define versões; dependencies declara o uso. pluginManagement define padrões para os plugins acionados pelo ciclo ou pela configuração. provided é fornecido pelo container; test fica restrito aos testes; runtime atende à execução.
