Gerar a base REST no Spring Initializr

Gerar a base REST no Spring Initializr e importá-la no Eclipse.

1. O que fazer nesta etapa

Gerar a base REST no Spring Initializr e importá-la no Eclipse.

  1. Criar: source/restaurante-rest-openapi/pom.xml
  2. Criar: source/restaurante-rest-openapi/src/main/java/br/edu/soa/restaurante/rest/RestauranteApplication.java
  3. Criar: source/restaurante-rest-openapi/src/main/resources/application.properties
  4. Criar: source/restaurante-rest-openapi/src/test/java/br/edu/soa/restaurante/rest/RestauranteApplicationTests.java

A aula termina quando: O projeto REST está importado, seu POM valida e o teste inicial passa.

Continue no Eclipse após Gerar e conferir QR em localhost. Use os projetos e os arquivos que você construiu nas etapas anteriores.

2. Entenda o que será feito

Problema no sistema

A API REST precisa de um processo próprio com configuração Java, servidor embutido e um ponto de entrada. O Initializr cria a base que será importada e executada pelo Eclipse.

Entenda cada parte de maven-wrapper.properties
ParteO que faz e por que importa
wrapperVersionIdentifica a versão 3.3.4 do wrapper que acompanha o projeto.
distributionType=only-scriptIndica que a preparação da distribuição é feita pelos scripts fornecidos.
distributionUrlAponta para a distribuição Maven 3.10.0 escolhida no projeto gerado.

O Initializr fornece o bootstrap, o POM e o wrapper; as funções do restaurante serão implementadas nas próximas aulas.

  • Use a linha Spring Boot 4.1.2 documentada, Java 17, Maven, empacotamento JAR e Spring Web/Validation.
  • O projeto REST tem seu próprio parent Boot; permanece separado do WAR SOAP.

3. Faça o passo a passo

Passo 1: Gerar e importar a base pelo Initializr

  1. Abra Spring Initializr no navegador. Selecione Maven, Java, Spring Boot 4.1.2, Packaging JAR e Java 17.
  2. Informe Group br.edu.soa, Artifact restaurante-rest-openapi, Name Restaurante e Package name br.edu.soa.restaurante.rest. Acrescente Spring Web e Validation.
  3. Gere o ZIP e extraia seu conteúdo em laboratorio-restaurante-soa/source/restaurante-rest-openapi, com pom.xml diretamente nessa pasta.
  4. No Eclipse, use File → Import… → Maven → Existing Maven Projects, selecione essa pasta e conclua a importação.
  5. Compare os arquivos de bootstrap mostrados nesta aula e preserve os wrappers gerados. O núcleo será integrado na aula 68.

O parent REST é independente do BOM usado pelo SOAP. A linha Boot 4.1 usa os pacotes de teste e bibliotecas próprios do seu catálogo. Requisitos oficiais do Spring Boot.
