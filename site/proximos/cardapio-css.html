Continue no Eclipse após Escrever o HTML semântico. Use os projetos e os arquivos que você construiu nas etapas anteriores.

2. Entenda o que será feito

O CSS organiza grade, espaçamento, cores, foco e adaptação à largura disponível.

  • Teste a navegação por teclado e o foco visível.
  • O estilo trata da apresentação; os dados serão carregados no próximo passo da trilha.
Pontos para observar no código
  • Grid define a grade; media queries mudam a organização conforme largura.
  • focus-visible mantém foco reconhecível por teclado.
  • Nenhum preço é calculado pelo CSS.

Passo 4: Verificar pelo Maven no Eclipse

  1. Use File → Save All.
  2. No projeto restaurante-soap, clique com o botão direito e escolha Run As → Maven build…. Use um nome identificável, como Verificar aula 63.
  3. Confira Base directory: selecione o projeto restaurante-soap com Browse Workspace…. Em Goals, informe o conteúdo abaixo, sem o prefixo mvn.
  4. Na aba JRE, confira o JDK 17. Clique em Apply → Run e acompanhe a aba Console.
-pl servidor -am package

Confira: a execução deve terminar em BUILD SUCCESS. Esse checkpoint valida o build desta etapa; a inicialização com banco e a interação pelas telas serão conferidas nas aulas de execução.

Passo 5: Republicar e conferir no navegador

  1. Na aba Servers, pare a instância Tomcat do laboratório antes de republicar.
  2. No projeto servidor, use Maven → Update Project… e confira os recursos configurados no POM. O cardápio deve ser incluído no caminho /cardapio.
  3. Na aba Servers, publique novamente o módulo servidor e inicie o Tomcat. Se os recursos não forem atualizados, confira a montagem em Properties → Deployment Assembly.
  4. No navegador, abra a URL abaixo e confira o resultado específico desta aula.
http://localhost:8080/restaurante/cardapio/index.html?mesa=2

  1. Abra os arquivos salvos nos caminhos indicados e compare com a versão desta etapa.
