1. Objetivo do tutorial

Distinguir o Java do Eclipse, o Java de compilação e o Java do servidor.

2. Conceitos necessários

Problema no sistema

Antes de construir o sistema, cada processo precisa de uma ferramenta e de uma porta previsíveis. Esse mapa permite localizar onde ocorreu um problema quando o navegador ou o cliente Swing não recebe a resposta esperada.

Entenda os componentes desta etapa
ParteO que faz e por que importa
JDK 17Fornece as ferramentas de compilação e o nível Java adotado pelos módulos.
Eclipse e MavenA IDE organiza os projetos e os lançamentos. O Maven resolve dependências, compila e empacota conforme os POMs.
8080 e 8081Separam a publicação do Tomcat SOAP e o processo Spring Boot REST na configuração local do curso.
banco e configuraçãoA URL do banco indica host, porta e esquema. As credenciais são fornecidas ao processo que executa o adaptador.
localhostIdentifica o computador onde a URL é usada. Cada teste deve apontar para o processo e a porta daquela etapa.

JDK inclui javac; JRE executa bytecode. PATH seleciona executáveis, JAVA_HOME identifica a raiz do JDK.

São necessários JDK 17, Maven 3.6.3+, Eclipse Enterprise Java/Web, MySQL 8.4 LTS e Tomcat 10.1. A IDE pode exigir um JDK superior para iniciar; o projeto continua com release 17. O REST gerado no Initializr usa Boot 4.1.2 e servidor embutido próprio; ele não será copiado para o Tomcat 10.1.

Verifique cada ferramenta separadamente. Não tente executar o sistema inteiro antes de construí-lo. Se já existir servidor na porta 3306 ou 8080, identifique-o antes de alterar configuração. XAMPP pode oferecer MariaDB mesmo quando o painel mostra o nome MySQL; confirme SELECT VERSION().

Os comandos deste tutorial são apenas um diagnóstico inicial: uma ferramenta ainda não instalada pode informar comando não encontrado. Instale-a no tutorial correspondente e repita a verificação; esse diagnóstico não é um checkpoint de build.

3. Problema que será resolvido

Evitar uma IDE funcional com projeto ou servidor configurado para uma versão incompatível.
