Instalar e configurar o JDK 17

Instalar um JDK e configurar a sessão do PowerShell sem adivinhar caminhos.

1. Objetivo do tutorial

Instalar um JDK e configurar a sessão do PowerShell sem adivinhar caminhos.

2. Conceitos necessários

Uma distribuição JDK oferece as ferramentas de desenvolvimento da plataforma Java. A pasta raiz contém bin, conf e lib.

Baixe um JDK 17 para Windows x64 em uma distribuição confiável, como Eclipse Temurin. Escolha JDK, não apenas JRE. Execute o instalador ou extraia a distribuição e anote a pasta real. Não copie uma pasta ilustrativa com XX.

Abra um PowerShell novo, configure JAVA_HOME com o caminho identificado e acrescente seu bin ao início do PATH da sessão. Verifique a existência dos dois executáveis antes de prosseguir. Para persistir a escolha, use Configurações avançadas do sistema → Variáveis de Ambiente; mantenha outras entradas do PATH.

No Eclipse, Window → Preferences → Java → Installed JREs → Add → Standard VM. Selecione a raiz do JDK 17, dê um nome claro e associe JavaSE-17 em Execution Environments. O Java de inicialização do Eclipse continua independente.

3. Problema que será resolvido

O comando java pode ser um redirecionador do Windows; o caminho do comando não é necessariamente JAVA_HOME.

5. Implementação passo a passo e código da etapa

Execute os passos na ordem apresentada. Não há arquivo de solução para importar no início. Quando um arquivo evolui, a versão completa abaixo corresponde exatamente a esta etapa.

Passo 1: Baixar o arquivo ZIP

  1. Acesse o site oficial de downloads de uma distribuição Java (como o Oracle Java SE, o Eclipse Temurin, ou o Azul Zulu).
  2. Escolha a versão Java 17 LTS.
  3. Selecione o sistema operacional Windows e a arquitetura x64.
  4. Procure pela opção de download com a extensão Compressed Archive (.zip) e baixe o arquivo

Passo 2: Extrair os arquivos

  1. Crie uma pasta organizada no seu computador para centralizar suas versões do Java, por exemplo: C:\Java\
  2. Clique com o botão direito no arquivo .zip que você baixou e selecione Extrair Tudo
  3. Extraia o conteúdo diretamente para a pasta que você criou. O resultado final será uma pasta parecida com C:\Java\jdk-17.0.x\

Passo 3: Extrair os arquivos

Como o ZIP não possui um instalador automático, você precisa avisar ao Windows onde o Java está localizado.

  1. No menu Iniciar do Windows, digite "Variáveis de ambiente" e clique em Editar as variáveis de ambiente do sistema.
  2. Na janela que se abrir, clique no botão Variáveis de Ambiente... no canto inferior direito.
  3. Em Variáveis do Sistema, clique em Novo... para criar a variável de base:
    1. Nome da variável: JAVA_HOME
    2. Valor da variável: O caminho exato da pasta que você extraiu (Ex: C:\Java\jdk-17.0.x)
    3. Clique em OK.
  4. Ainda em Variáveis do Sistema, procure pela variável chamada Path e clique em Editar....
  5. 1. Clique em Novo no menu lateral direito e adicione o seguinte texto exatamente como está: %JAVA_HOME%\bin
  6. Clique em OK em todas as janelas para salvar as alterações.
