Passo 1: Criar os bancos de dados do restaurante

Para os projetos SOAP e REST, criaremos dois bancos de dados independentes utilizando o MariaDB disponibilizado pelo XAMPP.

  1. Inicie Apache e MySQL no XAMPP Control Panel.
  2. Abra o navegador e acesse http://localhost/phpmyadmin/ .
  3. Na página inicial do phpMyAdmin, clique na aba SQL.
  4. Insira os comandos abaixo.
CREATE DATABASE IF NOT EXISTS restaurante_soap
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

CREATE DATABASE IF NOT EXISTS restaurante_rest
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

Explicação do código:

  • CREATE DATABASE: cria um novo banco de dados.
  • IF NOT EXISTS: evita erro caso o banco já exista.
  • restaurante_soap: banco utilizado pelo serviço SOAP.
  • restaurante_rest: banco utilizado pelo serviço REST.
  • CHARACTER SET utf8mb4: permite armazenar caracteres Unicode, incluindo acentos e emojis.
  • COLLATE utf8mb4_unicode_ci: define regras para comparação e ordenação de textos sem diferenciar letras maiúsculas e minúsculas.
  1. Clique em Executar.
  2. Atualize a lista de bancos de dados.
  3. Confirme a criação dos bancos restaurante_soap e restaurante_rest.

Passo 2: Criar o usuário do banco de dados

Não é recomendado utilizar a conta administrativa root nas aplicações. Criaremos um usuário específico para acessar os bancos do restaurante.

No phpMyAdmin, utilizando uma conta com privilégios administrativos, execute: 

CREATE USER 'restaurante'@'localhost'
IDENTIFIED BY 'SUA_SENHA_SEGURA';

Explicação do código:

  • CREATE USER: cria um usuário no servidor MariaDB.
  • 'restaurante': nome da conta utilizada pelas aplicações.
  • 'localhost': identifica o host local autorizado para essa conta.
  • IDENTIFIED BY: define a senha do usuário.

Atenção: substitua SUA_SENHA_SEGURA por uma senha própria. Não salve a senha real em arquivos SQL publicados ou enviados para repositórios.

Execute o comando apenas uma vez. Se a conta já existir, o MariaDB poderá informar que o usuário está duplicado. Nesse caso, não é necessário recriá-lo.

Passo 3: Conceder permissões ao usuário

O usuário foi criado, mas ainda precisa receber as permissões necessárias para acessar os bancos.

Execute:

GRANT SELECT, INSERT, UPDATE, DELETE,
CREATE, ALTER, INDEX, REFERENCES
ON restaurante_soap.*
TO 'restaurante'@'localhost';

GRANT SELECT, INSERT, UPDATE, DELETE,
CREATE, ALTER, INDEX, REFERENCES
ON restaurante_rest.*
TO 'restaurante'@'localhost';

Explicação das permissões:

  • SELECT: permite consultar registros.
  • INSERT: permite cadastrar registros.
  • UPDATE: permite atualizar informações existentes.
  • DELETE: permite excluir registros.
  • CREATE: permite criar tabelas e outras estruturas.
  • ALTER: permite alterar estruturas existentes.
  • INDEX: permite criar e remover índices.
  • REFERENCES: é um privilégio associado à definição de relacionamentos por chaves estrangeiras.

A expressão restaurante_soap.* representa todas as tabelas do banco restaurante_soap.

O mesmo procedimento é aplicado ao banco restaurante_rest.

Observação: essas permissões são adequadas para um ambiente didático que também executa migrações de tabelas. Em produção, separe as permissões de manutenção das operações cotidianas.

Passo 4: Verificar os bancos e as permissões

Para confirmar se os bancos foram criados, execute no phpMyAdmin: 

SHOW DATABASES;

O resultado deverá incluir: 

restaurante_soap
restaurante_rest

Agora verifique os privilégios do usuário: 

SHOW GRANTS FOR 'restaurante'@'localhost';

O comando apresenta as permissões concedidas à conta restaurante.

Passo 5: Verificar a conexão pelo PowerShell

Também podemos utilizar o cliente MariaDB instalado com o XAMPP para testar a conexão.

  1. Abra o PowerShell.
  2. Acesse a pasta de executáveis do banco.
cd C:\xampp\mysql\bin

Para conectar com a conta administrativa: 

.\mysql.exe -u root -p

Informe a senha quando solicitada. Se a conta não tiver senha na instalação local, pressione Enter.

Após conectar, execute: 

SHOW DATABASES;

SELECT VERSION();

SHOW DATABASES apresenta os bancos existentes. SELECT VERSION() mostra a versão do servidor de banco de dados.

Para encerrar a conexão:

EXIT;

Passo 6: Testar o usuário restaurante

Agora verificaremos se a conta criada consegue acessar os dois bancos.

No PowerShell, execute:

cd C:\xampp\mysql\bin

.\mysql.exe -u restaurante -p

Informe a senha definida na criação do usuário e execute: 

USE restaurante_soap;

SELECT DATABASE();

USE restaurante_rest;

SELECT DATABASE();

O comando USE seleciona o banco de dados ativo.

O comando SELECT DATABASE() informa qual banco está selecionado.

Se ambos os comandos funcionarem, o usuário conseguiu selecionar os dois bancos.

Para conferir também os privilégios concedidos à sessão atual, execute: 

SHOW GRANTS;

Por fim, encerre a conexão: 

EXIT;

Passo 7: Resolver problemas comuns

Apache não inicia

Verifique se as portas 80 ou 443 estão sendo utilizadas por outro serviço, como IIS ou outra instalação do Apache. Consulte os logs do XAMPP.

MySQL não inicia

Verifique se a porta 3306 está ocupada por outra instalação do MySQL ou MariaDB. Não exclua arquivos da pasta de dados para tentar resolver o problema.

phpMyAdmin não abre

Confirme que Apache e MySQL estão ativos. Depois, acesse: http://localhost/phpmyadmin/ .

Erro: Access denied for user

Verifique se o nome do usuário, a senha e o host estão corretos. Confira também as permissões concedidas com o comando SHOW GRANTS.

Erro: Can't connect to MySQL server

Verifique se o serviço MySQL está iniciado no XAMPP e se a aplicação utiliza a porta correta.

Passo 8: Encerrar os serviços

  1. Abra o XAMPP Control Panel.
  2. Clique em Stop na linha MySQL.
  3. Clique em Stop na linha Apache.
  4. Aguarde a interrupção completa dos serviços antes de fechar o painel.

Observações importantes

O XAMPP será utilizado principalmente como ambiente local para disponibilizar o banco MariaDB dos projetos.

Os serviços SOAP e REST desenvolvidos em Java serão executados pelo Apache Tomcat 10.1, quando empacotados como aplicações WAR compatíveis.

O phpMyAdmin deve permanecer restrito ao ambiente local, e as aplicações não devem utilizar a conta root.

Os bancos e usuários estão configurados. Na próxima etapa, será necessário criar as tabelas do restaurante, como produto, categoria, pedido e item_pedido, e configurar a conexão JDBC no Java.
