5. Implementação passo a passo e código da etapa

Passo 1: Baixar o instalador do XAMPP

O XAMPP é um ambiente de desenvolvimento que reúne ferramentas como Apache HTTP Server, MariaDB, PHP e phpMyAdmin. Ele permite desenvolver e testar aplicações web e bancos de dados localmente.

  1. Acesse o site oficial do Apache Friends: Baixar XAMPP .
  2. Localize a seção XAMPP para Windows.
  3. Escolha uma versão disponível compatível com seu sistema operacional.
  4. Clique em Download (64 bit) para baixar o instalador executável.
  5. Aguarde a conclusão do download. O arquivo terá um nome semelhante a xampp-windows-x64-VERSAO-installer.exe.

Passo 2: Executar o instalador

  1. Acesse a pasta Downloads do Windows.
  2. Localize o arquivo executável do XAMPP.
  3. Clique duas vezes no arquivo para iniciar a instalação.
  4. Caso o Windows solicite autorização para executar o programa, confirme somente após verificar sua origem.
  5. Na tela inicial do assistente, clique em Next.
  6. Se aparecer algum aviso relacionado ao Controle de Conta de Usuário (UAC), leia a mensagem antes de prosseguir.

Passo 3: Selecionar os componentes

O instalador poderá apresentar uma lista de componentes. Para este tutorial, utilizaremos principalmente Apache, MariaDB e phpMyAdmin.

  1. Mantenha selecionado Apache, responsável por atender requisições HTTP.
  2. Mantenha selecionado MySQL. No painel do XAMPP, esse nome normalmente identifica o MariaDB incluído na distribuição.
  3. Selecione PHP, utilizado pelo phpMyAdmin e por aplicações PHP.
  4. Selecione phpMyAdmin, ferramenta web para administrar bancos de dados.
  5. Os demais componentes são opcionais e podem variar conforme a versão instalada.
  6. Clique em Next para continuar.

Passo 4: Escolher a pasta de instalação

  1. Na tela de destino, escolha a pasta onde o XAMPP será instalado.
  2. Recomenda-se utilizar: C:\xampp
  3. Evite instalar em diretórios com restrições de escrita, como C:\Program Files.
  4. Clique em Next.
  5. Conclua as etapas restantes do assistente e clique em Install quando solicitado.
  6. Após a instalação, clique em Finish.

Passo 5: Abrir o XAMPP Control Panel

O XAMPP Control Panel permite iniciar, interromper e administrar os serviços instalados.

  1. Abra o menu Iniciar do Windows.
  2. Procure por XAMPP Control Panel.
  3. Alternativamente, acesse a pasta de instalação e execute: C:\xampp\xampp-control.exe
  4. Localize as linhas correspondentes ao Apache e ao MySQL.
  5. Clique em Start na linha Apache.
  6. Clique em Start na linha MySQL.
  7. Verifique se os serviços foram iniciados sem mensagens de erro.

Passo 6: Testar o servidor Apache

Com o serviço Apache iniciado, abra seu navegador de internet.

  1. Digite o endereço: http://localhost/
  2. Pressione Enter.
  3. Se a instalação estiver funcionando, a página inicial do XAMPP deverá ser exibida.
  4. Caso o endereço não funcione, confira se o Apache foi iniciado e se a porta 80 está disponível.

Passo 7: Acessar o phpMyAdmin

O phpMyAdmin permite criar bancos, tabelas, usuários e executar comandos SQL através do navegador.

  1. Verifique se Apache e MySQL estão iniciados.
  2. No navegador, acesse: http://localhost/phpmyadmin/
  3. Aguarde a abertura da interface.
  4. Localize a aba SQL.
  5. Utilize essa aba para executar os comandos SQL dos exercícios.

Passo 8: Resolver problemas comuns

Apache não inicia

Verifique se a porta 80 ou 443 já está sendo utilizada por outro servidor, como IIS ou outra instalação do Apache. Consulte os logs do XAMPP.

MySQL não inicia

Verifique se a porta 3306 já está sendo utilizada por outra instalação do MySQL ou MariaDB. Não exclua arquivos da pasta de dados para tentar corrigir o problema.

phpMyAdmin não abre

Confira se Apache e MySQL estão ativos. Utilize o endereço local correto e verifique os logs dos serviços.

Erro de acesso negado ao banco

Confirme o usuário, a senha e as permissões configuradas. Para aplicações, crie uma conta própria com privilégios limitados, evitando utilizar root.

Passo 11: Encerrar os serviços

  1. Abra o XAMPP Control Panel.
  2. Clique em Stop na linha MySQL.
  3. Clique em Stop na linha Apache.
  4. Aguarde a interrupção completa antes de fechar o painel.

Observações importantes

O XAMPP é destinado principalmente ao desenvolvimento e aos testes locais. Não deve ser publicado diretamente na internet com as configurações padrão.

O phpMyAdmin deve permanecer acessível somente localmente, e as contas administrativas devem ser protegidas.

Nos projetos Java SOAP e REST, o XAMPP pode fornecer o banco MariaDB. Para executar aplicações Java WAR, utilizaremos o Apache Tomcat 10.1 instalado separadamente.
