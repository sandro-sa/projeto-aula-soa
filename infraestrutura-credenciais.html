2. Entenda o que será feito

Problema no sistema

O servidor precisa distinguir a identidade de quem cadastra produtos e de quem atende pedidos. Credenciais reconhece os usuários do laboratório e devolve o papel que os adaptadores usarão para autorização.

As senhas chegam da configuração externa; a classe devolve o papel reconhecido para a autorização.

  • As duas senhas precisam ser distintas e ter pelo menos 12 caracteres.
  • Não escreva seus valores reais no código ou no registro de evidências.
Pontos para observar no código
  • O construtor recusa configuração insegura/ausente.
  • autenticar retorna ADMIN/GARCOM ou null; não registra senhas.
  • A comparação usa MessageDigest.isEqual, sem transformar erro em mensagem contendo credencial.

// Finalidade: Reconhecer identidades e papéis pelas senhas da configuração externa.
package br.edu.soa.restaurante.infraestrutura;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;

/** Identidades locais de laboratório. Publicação: HTTPS obrigatório, substituir por IdP. */
public final class Credenciais {
    private final String admin;
    private final String garcom;
    public Credenciais(String admin, String garcom) {
        if (admin == null || garcom == null || admin.length() < 12 || garcom.length() < 12 || admin.equals(garcom))
            throw new IllegalStateException("Configure senhas distintas de pelo menos 12 caracteres em RESTAURANTE_ADMIN_PASSWORD e RESTAURANTE_GARCOM_PASSWORD.");
        this.admin = admin; this.garcom = garcom;
    }
    // Compara a identidade recebida e devolve o papel reconhecido.
    public String autenticar(String usuario, String senha) {
        if (senha == null) return null;
        String esperada = "admin".equals(usuario) ? admin : "garcom".equals(usuario) ? garcom : null;
        return esperada != null && MessageDigest.isEqual(esperada.getBytes(StandardCharsets.UTF_8),senha.getBytes(StandardCharsets.UTF_8))
            ? ("admin".equals(usuario) ? "ADMIN" : "GARCOM") : null;
    }
}

Confira: o arquivo pertence ao projeto infraestrutura, no caminho indicado e com o conteúdo completo desta etapa.

Entenda cada parte de Credenciais.java

Módulo infraestrutura · Pacote br.edu.soa.restaurante.infraestrutura · Fontes src/main/java.

Parte O que faz e por que importa
campos admin e garcom Guardam as senhas fornecidas na configuração de execução do processo.
construtor Exige duas senhas distintas com pelo menos 12 caracteres. Uma configuração inválida interrompe a inicialização.
autenticar Escolhe a senha esperada para o nome informado e devolve ADMIN, GARCOM ou null conforme a comparação.
UTF-8 e MessageDigest.isEqual Convertem os textos para bytes com a mesma codificação e comparam esses bytes.
papel devolvido A identidade reconhecida é passada às regras de acesso do adaptador. Cada operação decidirá quais papéis são aceitos.

Fundamentação e leitura complementar

Fundamentação nos PDFs fornecidos

Separe autenticar uma identidade de autorizar uma ação. As senhas do laboratório vêm do ambiente e as identidades ADMIN/GARCOM têm permissões diferentes. Base64 é codificação reversível, não criptografia.
