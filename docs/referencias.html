Como as referências foram usadas

Os nove PDFs originais estão Raiz. A leitura foi dirigida aos trechos listados abaixo, com conferência de autoria nas capas, extração de texto quando disponível e leitura visual das páginas digitalizadas de Schildt. A consulta não representa uma leitura integral de todos os livros.

Paginação: Número da página no arquivo PDF, contado a partir da capa como página 1; não é a numeração impressa. Um link “página 554”, por exemplo, usa a página 554 do arquivo, mesmo que a folha mostre outro número.

Cada uma das 85 aulas apresenta uma aplicação do conceito, referências de capítulo/páginas e uma pergunta de compreensão. Os exemplos, regras e código do restaurante são desenvolvidos pelo tutorial. Os PDFs orientam conceitos; versões e comandos de Java 17, Jakarta, Maven, MySQL, Tomcat, Spring Initializr e OpenAPI são complementados pelas documentações oficiais.

SOA aplicado, REST e Arquitetura Limpa são as referências principais. Java para iniciantes, Java 8 Prático e o guia OCA apoiam a linguagem. JPA, JavaFX e JSF fornecem comparações delimitadas: a implementação continua JDBC/Flyway, Swing e HTML/CSS/JavaScript.

Os links abrem os arquivos originais. Pela prévia localhost, o servidor fornece somente os PDFs cadastrados; ao abrir este HTML diretamente do disco, os links usam os caminhos locais. Se os livros forem movidos, defina SOA_REFERENCIAS_DIR antes de gerar a bibliografia e iniciar a prévia.

Leitura crítica e adaptações

  • Java e Jakarta: os exemplos antigos de serviços não determinam as dependências do projeto Java 17. A geração usa Maven/Metro. javax.swing, javax.sql e javax.xml.namespace continuam sendo APIs Java SE; não se troca todo prefixo javax por jakarta.
  • Persistência: conceitos de transação, associação e concorrência de JPA Eficaz são comparados à implementação JDBC. O laboratório não usa EntityManager, @Version ou ORM e não presume o isolamento do MySQL a partir das descrições do exemplar.
  • Arquitetura: o projeto aplica a direção das dependências, mas agrupa casos de uso em Restaurante e não replica todas as portas/apresentadores do diagrama de Martin. A proposta do livro e a simplificação didática são explicitadas nas aulas.
  • REST: o exemplar discute HATEOAS; a API didática implementa recursos, métodos e status com URLs conhecidas. OpenAPI descreve essa API e não acrescenta navegação por hipermídia. HATEOAS permanece uma extensão a implementar e testar.
  • Java 8 Prático: a discussão da ausência de Stream.toList pertence ao Java 8 do livro. O código da trilha tem alvo Java 17 e pode usar essa API posterior, sem atribuí-la ao exemplar.

HTTP: no PDF REST, p. 28, a associação de Accept incompatível com 415 precisa de atualização. 406 corresponde à negociação da resposta; 415, ao conteúdo recebido não suportado. Content-Type pode aparecer em requisições e respostas. Consulte a RFC 9110, §15.5.7 e §15.5.16.

Basic: apesar da terminologia no PDF SOA, p. 153, Base64 é codificação reversível, sem confidencialidade criptográfica. Consulte a RFC 4648, §12.
