## Adaptações

- JPA, JavaFX e JSF são referências comparativas: o projeto usa JDBC/Flyway, Swing e HTML/CSS/JavaScript.
- A direção das dependências segue Martin; casos de uso agrupados e retorno interno de entidades são simplificações declaradas.
- A API HTTP não implementa HATEOAS. Initializr, Boot e OpenAPI são complementos documentados, sem atribuição aos livros antigos.
- REST, PDF p. 28: 406 corresponde à negociação da resposta; 415, ao conteúdo recebido não suportado. Content-Type pode aparecer nos dois sentidos. [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html#name-406-not-acceptable).
- SOA, PDF p. 153: Base64 é codificação reversível, sem confidencialidade criptográfica. [RFC 4648, §12](https://www.rfc-editor.org/rfc/rfc4648.html#section-12).
